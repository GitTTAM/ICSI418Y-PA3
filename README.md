# Matt's Task List for 418Y
Author: Matt Lawrence

## Description

Matt's Task List for 418Y is a small interactive web page for adding, completing, deleting, and timestamping tasks. Each task has a Low, Medium, or High priority.

## How to Run

Open `index.html` in a web browser.

## Known Problems or Incomplete Features

Tasks are stored only while the page is open. They disappear when the page is refreshed.
